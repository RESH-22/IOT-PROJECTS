# Run Projects in Tinkercad (Simulation)

You can also simulate these projects online using **Tinkercad Circuits** (no hardware needed).

### 🔧 Steps to Run in Tinkercad

1. Go to 👉 https://www.tinkercad.com  
2. Sign in / Create an account  
3. Click on **Circuits** → **Create New Circuit**  
4. Drag and drop components:
   - Arduino UNO  
   - Breadboard  
   - Sensors (LDR, LED, Resistors, etc.)  

5. Connect components as per circuit diagram:
   - LDR → Analog pin (A0)  
   - LED → Digital pin (D13 or any)  
   - Use resistors properly  

6. Click on **Code** → Select **Text Mode**  

7. Copy and paste Arduino code from this repository  

8. Click **Start Simulation** ▶️  

---

### Example: LDR Street Light in Tinkercad

- When light intensity is LOW → LED turns ON  
- When light intensity is HIGH → LED turns OFF  

This simulates **automatic street lighting system**.

---

### Notes

- ESP8266 and RF modules are **not fully supported in Tinkercad**  
- For those projects, use:
  - Real hardware OR  
  - Proteus / other simulators
